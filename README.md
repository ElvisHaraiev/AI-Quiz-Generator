# AI Quiz Generator

> ⚠️ **DEMO / демонстраційна версія.**
>
> Проєкт у розробці й **не є завершеним продуктом**. Частина функцій реалізована повністю, частина — експериментальна й потребує ручної перевірки. Використовуйте на власний розсуд.

**AI Quiz Generator** — розширення для браузера Chrome, яке перетворює навчальні матеріали (підручники, конспекти, методички) на готові тестові питання з варіантами відповідей за допомогою великих мовних моделей (LLM).

Користувач завантажує файл, описує тему звичайною мовою — і отримує готовий набір питань, який можна використати окремо або вставити в конструктор тестів.

## Можливості

### Реалізовано

- **Завантаження матеріалів** — PDF, DOCX, DOC, TXT (до 2 файлів, до 50 МБ кожен).
- **Витяг тексту** — PDF через `pdf.js`, Word через `JSZip`, зі збереженням номерів сторінок.
- **Очищення артефактів** — переноси слів, зайві пробіли, порожні сторінки.
- **Аналіз структури книги** — система сама визначає розділи, параграфи й теми незалежно від того, як вони оформлені.
- **Вибір релевантних розділів** — для книги на 300+ сторінок моделі надсилається не весь текст, а карта документа, що допомагає працювати в межах ліміту контексту.
- **Генерація питань** — `quiz` (одна правильна відповідь) і `multiquiz` (кілька правильних).
- **Ілюстрації** — програмні SVG-схеми для точних дисциплін (геометрія, графіки функцій, таблиці) та підбір реальних фото з відкритих джерел із перевіркою релевантності.
- **Контроль якості** — рівномірний розподіл правильних відповідей між варіантами, обов'язкове посилання на малюнок у тексті питання.
- **Чат з асистентом** — уточнення запиту, редагування та перегенерування питань.
- **Історія** — збереження чатів і наборів питань локально.

### Експериментально

- **Автоматична вставка в конструктор тестів** — модуль реалізовано, але він залежить від внутрішньої структури сторінки конструктора й потребує ручної перевірки в браузері.
- **Зображення в питаннях** — передаються як `data:`-URL; поведінка конкретного конструктора не гарантована.

### Не реалізовано

- OCR для PDF-сканів без текстового шару.
- Експорт у файли (JSON/CSV/DOCX).
- Локалізація інтерфейсу (наразі лише українська).

## Як це працює

1. **Завантаження.** Користувач додає PDF/DOCX/TXT і пише запит, наприклад: «зроби 10 питань за темою 2.4».
2. **Розбір.** Система витягує текст посторінково й очищує його від артефактів.
3. **Структура.** Будується карта документа: розділи, підрозділи, діапазони сторінок.
4. **Маршрутизація.** Модель отримує карту і сама обирає, які розділи потрібні для запиту. Це дозволяє працювати з великими підручниками.
5. **Генерація.** Модель повертає JSON із питаннями та варіантами відповідей.
6. **Перевірка.** Система перевіряє коректність, балансує позиції правильних відповідей, додає ілюстрації.
7. **Результат.** Питання з'являються у вкладці «Питання»; за потреби — вставляються в конструктор тестів (експериментально).

## Архітектура

| Файл | Призначення |
|---|---|
| `manifest.json` | Маніфест Chrome Extension (Manifest V3) |
| `popup.html` / `popup.css` | Інтерфейс користувача |
| `popup.js` | Стан, читання файлів, чат, історія, набори питань |
| `background.js` | Service worker: запити до LLM, обробка матеріалу, зображення |
| `content.js` | Міст між popup і сторінкою конструктора тестів |
| `injected.js` | Автоматизація сторінки конструктора |
| `lib/material.js` | Очищення тексту, розбиття на частини, карта документа |
| `lib/educational-images.js` | Генерація SVG та підбір зображень |
| `tools/check-pdfs.cjs` | Пакетна перевірка конвеєра на наборі PDF |
| `tests/` | Автоматичні тести (Node.js) |

## Встановлення

1. Клонуйте репозиторій:

   ```bash
   git clone <URL-репозиторію>
   ```

2. Відкрийте Chrome і перейдіть за адресою:

   ```text
   chrome://extensions/
   ```

3. Увімкніть **«Режим розробника»**.
4. Натисніть **«Завантажити розпаковане розширення»**.
5. Виберіть кореневу папку проєкту — ту, що містить `manifest.json`.

## Налаштування провайдера

У вкладці «AI-провайдер» виберіть провайдера й вставте API-ключ.

| Провайдер | Типова модель |
|---|---|
| OpenAI | `gpt-4o-mini` |
| Gemini | `gemini-3.6-flash` |
| DeepSeek | `deepseek-flash` |
| Mistral | `mistral-small-latest` |
| Manus | `manus-1.6-lite` |

Ключ зберігається локально в `chrome.storage.local` і не надсилається на сторонні сервери, крім обраного провайдера.

## Використання

1. Відкрийте розширення.
2. Перейдіть у вкладку «AI-провайдер».
3. Виберіть провайдера та вкажіть API-ключ.
4. Збережіть налаштування й перевірте з'єднання.
5. Завантажте файл із навчальним матеріалом.
6. Напишіть запит, наприклад: «створи 10 питань за темою 1.2».
7. Дочекайтеся результату у вкладці «Питання».
8. За потреби — відредагуйте питання в чаті або вставте їх у конструктор.

## Обмеження та відомі проблеми

- **PDF-скани без текстового шару** не обробляються — потрібен OCR.
- **Вбудовані шрифти зі зсунутою кодовою таблицею** можуть давати спотворений текст; це обмеження самого PDF.
- **Вставка в конструктор** залежить від внутрішньої структури сторінки й може зламатися після її оновлення.
- **Великі книги** обробляються частинами; карта документа покриває всю книгу, але в один запит потрапляє лише вибрана частина.
- **Демо-версія** не проходила повного тестування в реальному браузері.

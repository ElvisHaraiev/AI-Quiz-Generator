# AI Quiz Generator — AI-генератор тестів

Розширення для браузера Chrome, яке генерує тестові питання з ваших навчальних матеріалів за допомогою OpenAI, Gemini, DeepSeek, Manus або Mistral. Це загальний генератор тестів: готові питання можна використовувати окремо або вставити в конструктор тестів (підтримується НаУрок).

## Можливості

- **Завантаження навчальних матеріалів** — підтримка `.txt`, `.pdf`, `.docx`, `.doc` (до 2 файлів)
- **Гнучкі налаштування** — вибір кількості питань (5/10/15/20) та типів (звичайні, з картинками, мультивибір)
- **Автоматична вставка** — за потреби питання створюються у конструкторі тестів (підтримується НаУрок)
- **Безпека** — API токен зберігається локально у браузері

## Встановлення

### Спосіб 1: Завантаження в режимі розробника

1. Відкрийте Chrome і перейдіть до `chrome://extensions/`
2. Увімкніть **"Режим розробника"** (правий верхній кут)
3. Натисніть **"Завантажити розпаковане розширення"**
4. Виберіть **кореневу** папку проєкту — ту, що містить `manifest.json`
5. Розширення з'явиться у панелі інструментів

### Спосіб 2: Збірка .crx (для поширення)

1. Відкрийте `chrome://extensions/`
2. Увімкніть "Режим розробника"
3. Натисніть **"Пакувати розширення"**
4. Виберіть **кореневу** папку проєкту — ту, що містить `manifest.json`
5. Отримаєте файли `.crx` та `.pem`

## Використання

1. **Налаштуйте AI-провайдера** у вкладці «AI-провайдер» і вставте його API ключ:
   - OpenAI — модель `gpt-4o-mini`, Base URL `https://api.openai.com/v1`
   - Gemini — модель `gemini-3.6-flash` (Interactions API)
   - DeepSeek — модель `deepseek-flash`, Base URL `https://api.deepseek.com`
   - Manus — модель `manus-1.6-lite`, Base URL `https://api.manus.ai`
   - Mistral — модель `mistral-small-latest`, Base URL `https://api.mistral.ai/v1`

   Для DeepSeek доступні моделі `deepseek-flash` (типова, підтримує зображення на вхід) і `deepseek-v4-pro`.
   Для Gemini питання, яким дійсно потрібна ілюстрація, можуть отримувати навчальні зображення з Wikimedia Commons. Додатковий API ключ для пошуку не потрібен; посилання на джерело зберігається разом із питанням.

2. **Підготуйте файли** (до 2 шт.):
   - Текстові файли (`.txt`) — навчальні матеріали, конспекти, підручники
   - PDF документи (`.pdf`) — лекції, статті
   - Word документи (`.docx`, `.doc`)
   - Максимальний розмір одного файлу: **50 MB**
   - Максимальний сумарний розмір усіх файлів: **100 MB**

   Орієнтовно: підручник на 15 MB і 259 сторінок займає близько 1 MB у
   локальному сховищі розширення, тож кілька великих підручників поміщаються
   без проблем.

   Для PDF і `.txt` розширення зберігає текст **посторінково**. Якщо в запиті
   назвати тему (наприклад, «тема 1.2»), розділ або сторінку, у модель підуть
   саме ті частини матеріалу, а не перші 24 000 символів. Для довгих
   підручників у чаті з'являється примітка, які сторінки опрацьовано.

   Якщо PDF зібраний зі вбудованими шрифтами зі зсунутою кодовою таблицею,
   частина символів у витягнутому тексті буде спотворена (це обмеження самого
   PDF, а не розширення). У такому разі краще використати `.docx` або `.txt`.

3. **Відкрийте конструктор тестів (для автоматичної вставки, підтримується НаУрок)**:
   - Створіть новий тест на [naurok.com.ua/test/create](https://naurok.com.ua/test/create)
   - Перейдіть до конструктора питань (`naurok.com.ua/test/builder/...`)

4. **Запустіть генерацію**:
   - Клікніть іконку розширення у панелі Chrome
   - Вставте API токен
   - Завантажте файли з матеріалами
   - Напишіть запит, наприклад: «створи 10 питань за темою 1.2»
   - Натисніть **"Надіслати"**

5. **Дочекайтеся завершення** — питання з'являться у вкладці «Питання». Натисніть **«Вставити в конструктор»**, щоб створити їх у конструкторі.

## Підтримувані типи питань

| Тип | Опис | Приклад |
|-----|------|---------|
| `quiz` (звичайне) | Питання з 4 текстовими варіантами | "Що таке HTML?" |
| `quiz` (з картинкою) | Питання із зображенням | "Яка це технологія?" + фото |
| `quiz` (картинки-відповіді) | Варіанти є зображеннями | Логотипи технологій |
| `multiquiz` | Кілька правильних відповідей | "Виберіть всі веб-технології" |

## Вирішення проблем

### "Не вдалося отримати Angular scope"
- Переконайтесь, що сторінка конструктора повністю завантажена
- Оновіть сторінку і спробуйте знову
- Відкрийте консоль розробника (F12) → вкладка Console для деталей

### "Невірний OpenAI API токен"
- Перевірте, що токен дійсний і має формат `sk-...`
- Переконайтесь, що на рахунку є кошти (OpenAI вимагає поповнення)
- Спробуйте створити новий ключ API

### "Помилка читання PDF файлу"
- Переконайтесь, що PDF не захищений паролем
- Спробуйте конвертувати PDF в текстовий формат
- Максимальний розмір файлу — 50 MB

### "Матеріали занадто довгі"
- AI обробляє перші ~12,000 символів
- Розділіть матеріали на кілька файлів
- Використовуйте найбільш релевантні уривки

## Безпека та приватність

- API токен зберігається локально через `chrome.storage.local`
- Токен **ніколи** не відправляється на сторонні сервери
- Запити йдуть напряму до вибраного AI-провайдера
- Вміст файлів обробляється локально в браузері
- Розширення не збирає аналітику та не відстежує користувачів
